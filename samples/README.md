# Lectern samples

Open this file with `lectern samples/README.md`, then follow the links. Each file
exercises one area of the viewer.

| Sample | What it covers |
|--------|----------------|
| [GFM elements](gfm.md) | Every GitHub-Flavored Markdown element, front matter, raw HTML, alerts, code highlighting |
| [Diagrams](diagrams.md) | Mermaid flowchart, sequence, gantt, class, state, pie; Graphviz |
| [Math](math.md) | KaTeX inline and display math |
| [Images](images.md) | PNG, JPG, GIF, WebP, SVG; relative, `../`, absolute-ish and remote images; lightbox |
| [Headings](headings.md) | Duplicate headings, slug edge cases, deep links |
| [Long document](long.md) | 40 sections for scroll-spy and TOC scrolling |
| [Broken things](broken.md) | Broken Mermaid, Graphviz and math, missing images, dead links |
| [Security](security.md) | XSS attempts that must be neutralised |
| [Nested file](nested/other.md) | Relative links across directories |

## Things to try

- Edit any of these files in another editor and save: the view reloads in place.
- Press <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> to cycle themes. Code and diagrams follow.
- Press <kbd>Ctrl</kbd>+<kbd>F</kbd> and search for "mermaid".
- Press <kbd>Ctrl</kbd>+<kbd>\\</kbd> to toggle the table of contents.
- Use <kbd>Alt</kbd>+<kbd>←</kbd> to go back after following a link.
- External links such as <https://commonmark.org> open in your browser.
